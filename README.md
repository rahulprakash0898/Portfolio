## 🛠️ Tech Stack & Key Technologies

### **Frontend & Architecture**
- **React 19** & **TypeScript** – Component-driven modular architecture with strict type safety.
- **Vite 6** – Lightning-fast build tooling and zero-latency development server.
- **Tailwind CSS 4** – Utility-first cyber dark-mode design system with responsive tokens.
- **Motion (Framer Motion)** – Fluid scroll-triggered animations and dynamic transitions.
- **Lucide Icons** – Crisp SVG icons.

### **Backend, Database & Cloud Skills Featured**
- **Core Stacks:** Node.js, Express.js, RESTful APIs, WebSocket / Socket.IO, AI/LLM Integration.
- **Databases:** MongoDB, PostgreSQL, MySQL, Redis.
- **DevOps & Cloud:** Docker, Nginx, AWS EC2, AWS S3, GitHub Actions CI/CD, Linux/VPS.

## 💻 Local Setup & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rahulprakash0898/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build production bundle:**
   ```bash
   npm run build
   ```

## 🌐 Netlify Deployment

This repository is pre-configured for Netlify deployment:

1. Push your repository to GitHub: `https://github.com/rahulprakash0898/Portfolio`
2. Connect the repository in the **Netlify Dashboard**.
3. **Build settings:**
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
4. Deploy site – your portfolio will automatically be live at `https://rahulprakash-dev.netlify.app`.
